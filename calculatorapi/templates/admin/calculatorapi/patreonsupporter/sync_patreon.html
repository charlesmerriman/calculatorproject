Fetches the current member list straight from Patreon — no file to download or upload. Only each patron’s name, tier, status and pledge start date are requested; email addresses and postal addresses are behind permissions this connection does not hold, so they are never sent.

This never publishes a name. New supporters are added counted anonymously, and an existing supporter’s “Show name publicly” setting is left exactly as you set it. Publishing is always a separate, deliberate tick on the supporters list.
